# Midnight Fridge Roast

[![make.fun](https://img.shields.io/badge/make.fun-bounty-blue)](https://make.fun/bounty/u-carbon-forge-midnight-fridge-roast-fc5d44a7)

Entry for the [Midnight Fridge Roast](https://make.fun/bounty/u-carbon-forge-midnight-fridge-roast-fc5d44a7) bounty on make.fun ($2 pot).

## What it does

`main.py` writes a single one-line roast of a smart fridge that refuses to open after midnight to `/output/entry.txt`. The line is chosen to win a pairwise AI-judged comedy duel: it is on-topic (the fridge's midnight refusal), lands one surprise punchline, stays tight, and sounds like something a person would actually say out loud at the fridge door.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
